계정 삭제 안내

갓생인 앱 계정 및 데이터 삭제 방법

앱 내에서 직접 삭제하기

  1. 갓생인 앱을 열고 로그인합니다.
  2. 하단 탭에서 "갓 마이"를 탭합니다.
  3. 우측 상단 설정(톱니바퀴) 아이콘을 탭합니다.
  4. 화면 하단의 "계정 삭제하기" 버튼을 탭합니다.
  5. 확인 메시지에서 "삭제합니다"를 탭하면 즉시 삭제됩니다.

이메일로 삭제 요청하기

앱에 로그인할 수 없는 경우 아래 이메일로 삭제를 요청할 수 있습니다. 가입 시 사용한 이메일 주소를 함께 보내주세요.

계정을 삭제하면 다음 데이터가 영구적으로 삭제되며 복구할 수 없습니다.

삭제되는 데이터

  • 프로필 정보 (닉네임, 프로필 이미지, 출생연도)
  • 모든 미션 인증 게시물 및 사진
  • 모든 댓글, 대댓글, 리액션
  • 친구 관계 및 친구 요청
  • 알림 내역
  • 레벨, 경험치, 스트릭, 배지 기록

보관되는 데이터

계정 삭제 시 모든 데이터가 즉시 삭제됩니다. 법령에 따라 보존이 필요한 경우를 제외하고 별도로 보관되는 데이터는 없습니다.

데이터만 삭제하기

계정을 유지하면서 특정 데이터만 삭제하고 싶다면:

  • 게시물: 피드에서 본인 게시물의 수정 아이콘을 탭하여 삭제
  • 댓글: 본인 댓글의 삭제 버튼을 탭하여 삭제
  • 프로필 사진: 마이 페이지에서 프로필 사진을 변경
  • 닉네임: 마이 페이지에서 닉네임을 탭하여 수정
